# WEEX AI Trading Agent

AI-powered autonomous trading agent for WEEX exchange with x402 micropayment integration.

## Features
- AI-driven market analysis (RSI, MACD, Bollinger Bands)
- Three strategies: Trend Following, Mean Reversion, Sentiment Analysis
- x402 protocol for micro-payout settlements
- Multi-pair support: BTC/ETH/SOL/ARB vs USDT
- CMC API integration for market data
- Real-time P&L tracking and risk controls

## Tech Stack
- React 18 + Vite 5
- Tailwind CSS
- WEEX REST API
- CMC API
- x402 Payments
