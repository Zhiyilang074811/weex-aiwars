# WEEX AI Wars II — AI Trading Agent

AI-powered autonomous trading agent for the WEEX exchange with x402 micropayment integration.

## Features
- AI-driven market analysis and trade execution
- x402 protocol for micro-payouts
- Multi-pair support (BTC/ETH/SOL/ARB)
- Real-time P&L tracking
- Trend following, mean reversion, sentiment strategies

## Tech Stack
- React 18 + Vite 5
- Tailwind CSS
- WEEX API Integration
- x402 Payments
